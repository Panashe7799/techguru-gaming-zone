# TECHGURU Gaming Website

## Goal
Build a polished, mobile-first website that makes TECHGURU feel like Marondera’s premium gaming destination and drives WhatsApp enquiries, calls, visits, bookings, and event enquiries.

## Pages and navigation
- Create dedicated pages for Home, VR, PlayStation, Games, Pricing, Events, Gallery, and Contact.
- Add a shared desktop navigation and compact mobile menu, plus persistent mobile WhatsApp and Book Now actions.
- Use a consistent header/footer with the supplied address, both phone numbers, social placeholders, and the 2026 copyright notice.

## Visual direction
- Use a cinematic near-black arena aesthetic with controlled electric blue, purple, and cyan accents, crisp white typography, subtle glow, fine grid/particle details, and restrained glass effects.
- Generate a cohesive set of clearly illustrative gaming imagery for the venue atmosphere, VR, PlayStation, events, and gallery placeholders; never imply generated imagery is the real TECHGURU venue.
- Add lightweight entrance, hover, and section transitions with reduced-motion support and no heavy 3D or autoplay mobile video.

## Content and interactions
- Build the specified full-screen home introduction, exact headline/supporting copy, location marker, primary/secondary calls to action, experience cards, benefits, featured VR/PlayStation content, events, location, and final contact prompt.
- Build cinematic VR and PlayStation pages with the supplied copy, three-step VR flow, and editable placeholder game cards.
- Build a searchable and filterable games library using centralized placeholder data and the requested categories.
- Build premium pricing cards using `[PRICE]` placeholders only.
- Build an accessible booking form for gaming type, date, time, players, name, and phone; submit it through a context-aware prefilled WhatsApp message without adding payments.
- Build events, masonry gallery, review placeholders, contact, address, phone, WhatsApp, and directions experiences exactly from the supplied business information.

## Content safeguards
- Keep games, prices, gallery items, events, reviews, social links, and contact details in one editable content module.
- Do not invent prices, hours, reviews, emails, social accounts, specific available games, or additional services.
- Clearly label all generated gallery/venue imagery and review/game content as placeholders where appropriate.

## Technical details
- Use the existing TanStack routing and shared design components, with one route file and unique metadata per public page.
- Add local-business structured data and natural Marondera/Zimbabwe search language without keyword stuffing.
- Use responsive, lazy-loaded images, semantic headings, descriptive alt text, keyboard-friendly controls, visible focus states, and high contrast.
- Validate the finished experience at desktop and mobile sizes, including navigation, filters, WhatsApp messages, phone links, booking flow, directions, layout, and console output.
